Types of Units

  1. Pixel (px) - fixed units
  2. Percentage (%) - depends on parent
  3. View Width (vw) - depends on viewport width
  4. View Height (vh) - depends on viewport height
  5. viewport maximum (vmax) - depends on viewport maximum dimension
  6. viewport minimum (vmin) - depends on viewport minimum dimension
  7. Em (em) - according to parent and can be controlled by parent
  8. Rem (rem) - relative units
