Operators

  1. Arithmetic Operators:
    • + - * / % **
  2. Assignment Operators:
    • = += -= *= /= %=
  3. Comparision Operators:
    • == === != !== > < >= <=
  4. Logical Operators:
    • && || !
  5. Ternary Operators:
    • condition ? do this : do that
  6. Type Checking Operators:
    • Typeof
    • Instanceof
  7. String Operators:
    • + (concatination)
  8. Spread/rest Operators:
    • ... used for copying array etc bcz normally the references are copied
  9. Nullish Coalescing Operators:
    • Null ?? console.log("sorry") -> fallback if the value is Null / Undefined
  10. Optional Chaining
    • ?. (safe access to nested values)
